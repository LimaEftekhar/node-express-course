1-In this lesson, you created a middleware function called asyncWrapper. Why?
We create asyncWrapper for all our controllers because they perform asynchronous operations. Using try…catch blocks
in every controller quickly becomes redundant. The asyncWrapper is a middleware function that wraps our controllers
so that errors from async operations are automatically passed to the error handler. This way we don’t have to repeat
the same try/catch logic in each controller. There are even npm packages that provide this functionality.


2-Suppose that you want to make sure that both a status code and an error message are sent back to the user when they request
the URL for a task that does not exist. Assume that you’ve created a CustomAPIError class and an error handler that references
that class. Complete the code:

const getTask = asyncWrapper(async (req, res, next) => {  
  const { id: taskID } = req.params;  
  const task = await Task.findOne({ _id: taskID });
